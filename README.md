# 🎀 Grace Wang’s Portfolio

Welcome to my personal portfolio website — a place where I combine design, functionality, and a touch of AI to share who I am and what I build.

🔗 **Live Demo**: [gracewang.vercel.app](https://gracewang.vercel.app)

---

## 🖥️ Overview

This portfolio was built with modern web technologies like **Next.js**, **Tailwind CSS**, **Upstash**, and the **OpenAI API**. It’s a showcase of:

- My background and experiences  
- Technical projects  
- A custom-built AI chatbot 
- Ways to connect with me  

Whether you’re a recruiter, collaborator, or just curious — take a scroll!

---

## 🔧 Tech Stack

- **Framework**: Next.js (App Router)  
- **Styling**: Tailwind CSS  
- **Database / KV Store**: Upstash Redis  
- **AI Integration**: OpenAI API  
- **Hosting**: Vercel  
- **Icons**: Lucide

---

## ✨ Key Features

- 🎨 Clean, responsive design
- 🤖 Custom-built Chatbot using OpenAI  
- 📄 Dynamic pages for experiences, projects, and contact  
- 📨 Email integration with form
- ⚡ Deployed with Vercel
